## 6.1 Why Unity for Robotics Visualization?

While Gazebo excels at physics simulation and sensor modeling, **Unity** provides unparalleled visual fidelity and human-robot interaction capabilities.

### Unity's Strengths for Robotics

1. **Photorealistic Rendering**: Advanced graphics pipeline (URP, HDRP)
2. **Interactivity**: Built-in support for VR/AR and user interfaces
3. **Asset Ecosystem**: Vast library of 3D models, materials, and environments
4. **Cross-Platform**: Deploy to Windows, Linux, macOS, mobile, VR headsets
5. **Real-Time Performance**: Optimized rendering at 60+ FPS
6. **Human Simulation**: Realistic avatars for HRI testing
7. **Developer Tools**: Visual debugging, scene composition, prefab system

### Unity vs. Gazebo: Complementary Tools

| Feature | Gazebo | Unity |
|---------|--------|-------|
| **Physics Accuracy** | High (ODE, DART, Bullet) | Medium (PhysX, tunable) |
| **Visual Quality** | Basic | Photorealistic |
| **Sensor Simulation** | Excellent (LiDAR, IMU, cameras) | Good (cameras, raycasts) |
| **HRI Testing** | Limited | Excellent |
| **VR/AR Support** | None | Native |
| **Learning Curve** | Moderate (robotics-focused) | Moderate (game-focused) |
| **Best For** | Physics simulation, testing | Visualization, HRI, demos |

## 6.3 Unity-ROS 2 Communication Architecture

### 6.3.1 ROS-TCP-Endpoint

The **ROS-TCP-Endpoint** runs on your ROS 2 system and bridges ROS topics with Unity via TCP sockets.

**Installation**:

```bash
cd ~/ros2_ws/src
git clone https://github.com/Unity-Technologies/ROS-TCP-Endpoint.git
cd ~/ros2_ws
colcon build --packages-select ros_tcp_endpoint
source install/setup.bash
```

**Launch the Endpoint**:

```bash
ros2 run ros_tcp_endpoint default_server_endpoint --ros-args -p ROS_IP:=0.0.0.0
```

**Default Configuration**:
- **Port**: 10000
- **IP**: `0.0.0.0` (listens on all interfaces)
- **Protocol**: TCP with JSON serialization

**Setup in Unity**:

3. Configure:
   - **ROS IP Address**: `127.0.0.1` (localhost) or `<your-ros-machine-ip>`
   - **ROS Port**: `10000`
   - **Protocol**: `ROS2`
   - **Serializer**: `MessageSerializer`

```
    └── textures/
```

**Step 2: Import URDF into Unity**

```
1. Assets > Import Robot from URDF
2. Select URDF file: humanoid.urdf
3. Choose import settings:
   - Axis Conversion: Y-Up (Unity) from Z-Up (ROS)
   - Mesh Decomposer: VHACD (for collision)
   - Import Materials: Yes
4. Click Import
```

**Step 3: Verify Import**

Check the imported hierarchy:
```
HumanoidRobot (GameObject)
├── base_link
├── torso
│   ├── head
│   └── ...
├── left_arm
│   ├── left_shoulder
│   ├── left_elbow
│   └── left_hand
└── right_arm
    └── ...
```

Each link becomes a GameObject with:
- **MeshFilter**: Visual geometry
- **MeshRenderer**: Material rendering
- **ArticulationBody**: Joint physics (Unity's robot joint system)

### 6.4.2 Articulation Bodies

Unity uses **ArticulationBody** components (instead of Rigidbody + ConfigurableJoint) for robotic articulations.

**Advantages**:
- Better stability for long kinematic chains
- Direct support for revolute, prismatic, and fixed joints
- Reduced jitter compared to traditional joints

**Example Configuration**:

```csharp
// Access ArticulationBody for a joint
ArticulationBody shoulder = leftArmObject.GetComponent<ArticulationBody>();

// Read joint position
float currentAngle = shoulder.jointPosition[0]; // radians

// Set joint target (position control)
ArticulationDrive drive = shoulder.xDrive;
drive.target = 1.57f; // 90 degrees
shoulder.xDrive = drive;
```

## 6.5 Real-Time Robot State Synchronization

### 6.5.1 Publishing Joint States from ROS 2

**ROS 2 Joint State Publisher**:

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState

class JointStatePublisher(Node):
    def __init__(self):
        super().__init__('joint_state_publisher')
        self.publisher = self.create_publisher(JointState, '/joint_states', 10)
        self.timer = self.create_timer(0.02, self.publish_joint_states)  # 50 Hz

        self.joint_names = [
            'left_shoulder_pitch', 'left_shoulder_roll', 'left_elbow',
            'right_shoulder_pitch', 'right_shoulder_roll', 'right_elbow',
            'left_hip_pitch', 'left_knee', 'left_ankle',
            'right_hip_pitch', 'right_knee', 'right_ankle'
        ]

        self.positions = [0.0] * len(self.joint_names)

    def publish_joint_states(self):
        msg = JointState()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.name = self.joint_names
        msg.position = self.positions
        # Update positions based on robot controller output
        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    node = JointStatePublisher()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### 6.5.2 Subscribing to Joint States in Unity

**Unity C# Subscriber**:

```csharp
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Sensor;

public class JointStateSubscriber : MonoBehaviour
{
    private ROSConnection ros;
    private ArticulationBody[] articulationBodies;

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        ros.Subscribe<JointStateMsg>("/joint_states", UpdateJointStates);

        // Get all articulation bodies in robot
        articulationBodies = GetComponentsInChildren<ArticulationBody>();
    }

    void UpdateJointStates(JointStateMsg msg)
    {
        for (int i = 0; i < msg.name.Length; i++)
        {
            string jointName = msg.name[i];
            float position = (float)msg.position[i];

            // Find corresponding articulation body
            ArticulationBody body = FindArticulationByName(jointName);
            if (body != null)
            {
                // Set joint target position
                ArticulationDrive drive = body.xDrive;
                drive.target = position * Mathf.Rad2Deg; // Convert to degrees
                body.xDrive = drive;
            }
        }
    }

    ArticulationBody FindArticulationByName(string name)
    {
        foreach (var body in articulationBodies)
        {
            if (body.name.Contains(name))
                return body;
        }
        return null;
    }
}
```

### 6.5.3 Publishing Unity State to ROS 2

**Publish Robot Pose to TF**:

```csharp
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Geometry;

public class PosePublisher : MonoBehaviour
{
    private ROSConnection ros;
    public string topicName = "/unity/robot_pose";
    public float publishRate = 30f; // Hz

    private float timer = 0f;

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        ros.RegisterPublisher<PoseStampedMsg>(topicName);
    }

    void Update()
    {
        timer += Time.deltaTime;
        if (timer >= 1f / publishRate)
        {
            PublishPose();
            timer = 0f;
        }
    }

    void PublishPose()
    {
        PoseStampedMsg msg = new PoseStampedMsg();
        msg.header.stamp = new TimeStamp(Clock.time);
        msg.header.frame_id = "world";

        // Convert Unity coordinates to ROS (Unity: Y-up, ROS: Z-up)
        Vector3 unityPos = transform.position;
        msg.pose.position = new PointMsg(
            unityPos.z,   // ROS X = Unity Z
            -unityPos.x,  // ROS Y = -Unity X
            unityPos.y    // ROS Z = Unity Y
        );

        Quaternion unityRot = transform.rotation;
        msg.pose.orientation = new QuaternionMsg(
            unityRot.z, -unityRot.x, unityRot.y, unityRot.w
        );

        ros.Publish(topicName, msg);
    }
}
```

## 6.6 High-Fidelity Rendering in Unity

### 6.6.1 Render Pipelines

Unity offers three render pipelines:

**1. Built-in Render Pipeline** (Legacy):
- Simple, broad compatibility
- Limited visual quality
- Not recommended for new projects

**2. Universal Render Pipeline (URP)**:
- High performance, scalable
- Good for mobile, VR, and real-time robotics
- Recommended for most robotics applications

**3. High Definition Render Pipeline (HDRP)**:
- Photorealistic rendering
- Ray tracing, volumetric lighting
- Requires high-end GPU (RTX 4070 Ti+)
- Best for offline rendering, demos, presentations

:::tip Choosing a Pipeline
For real-time humanoid visualization with HRI: **Use URP** for 60+ FPS performance. For marketing videos or static renders: **Use HDRP** for maximum visual quality.
:::

```csharp
using UnityEngine;
using UnityEngine.AI;

public class HumanNavigator : MonoBehaviour
{
    private NavMeshAgent agent;
    public Transform[] waypoints;
    private int currentWaypoint = 0;

    void Start()
    {
        agent = GetComponent<NavMeshAgent>();
        agent.speed = 1.4f; // Average human walking speed (m/s)

            agent.SetDestination(waypoints[currentWaypoint].position);
        }
    }
```

```csharp
public class SafetyZone : MonoBehaviour
{
    public float detectionRadius = 2.0f; // meters
    public ArticulationBody[] robotJoints;
    private bool humanDetected = false;

    void Update()
    {
        // Check for humans in proximity
        Collider[] colliders = Physics.OverlapSphere(
            transform.position, detectionRadius, LayerMask.GetMask("Human")
        );

        humanDetected = colliders.Length > 0;

        if (humanDetected)
        {
            // Slow down robot movements
            foreach (var joint in robotJoints)
            {
                ArticulationDrive drive = joint.xDrive;
                drive.forceLimit = drive.forceLimit * 0.5f; // Reduce force
                joint.xDrive = drive;
            }
        }
    }

    void OnDrawGizmos()
    {
        Gizmos.color = humanDetected ? Color.red : Color.green;
        Gizmos.DrawWireSphere(transform.position, detectionRadius);
    }
}
```

### 6.7.3 Gesture and Gaze Tracking

**Simple Gaze Direction**:

```csharp
public class GazeTracker : MonoBehaviour
{
    public Transform head;
    public Transform gazeTarget; // What human is looking at

    void Update()
    {
        if (gazeTarget != null)
        {
            Vector3 direction = (gazeTarget.position - head.position).normalized;
            head.rotation = Quaternion.LookRotation(direction);
        }
    }

    public bool IsLookingAt(Transform obj, float angleThreshold = 15f)
    {
        Vector3 toObject = (obj.position - head.position).normalized;
        Vector3 gazeDir = head.forward;
        float angle = Vector3.Angle(gazeDir, toObject);
        return angle < angleThreshold;
    }
}
```

**Hand Gesture Recognition** (Simple):

```csharp
public class GestureDetector : MonoBehaviour
{
    public Transform rightHand;
    public float raiseThreshold = 1.5f; // meters above ground

    public bool IsHandRaised()
    {
        return rightHand.position.y > raiseThreshold;
    }

    public bool IsPointing(out Vector3 pointDirection)
    {
        // Check if arm is extended
        float armLength = Vector3.Distance(rightHand.position, transform.position);
        if (armLength > 0.6f) // Extended arm ~60cm
        {
            pointDirection = (rightHand.position - transform.position).normalized;
            return true;
        }
        pointDirection = Vector3.zero;
        return false;
    }
}
```

## 6.8 Interactive Camera Systems

### 6.8.1 Orbit Camera for Robot Inspection

```csharp
using UnityEngine;

public class OrbitCamera : MonoBehaviour
{
    public Transform target; // Robot to orbit around
    public float distance = 5.0f;
    public float rotationSpeed = 100f;
    public float zoomSpeed = 2f;

    private float currentX = 0f;
    private float currentY = 30f;

    void Update()
    {
        // Mouse orbit
        if (Input.GetMouseButton(1)) // Right mouse button
        {
            currentX += Input.GetAxis("Mouse X") * rotationSpeed * Time.deltaTime;
            currentY -= Input.GetAxis("Mouse Y") * rotationSpeed * Time.deltaTime;
            currentY = Mathf.Clamp(currentY, -80f, 80f); // Prevent flipping
        }

        // Mouse wheel zoom
        distance -= Input.GetAxis("Mouse ScrollWheel") * zoomSpeed;
        distance = Mathf.Clamp(distance, 1f, 20f);

        UpdateCameraPosition();
    }

    void UpdateCameraPosition()
    {
        Quaternion rotation = Quaternion.Euler(currentY, currentX, 0);
        Vector3 offset = rotation * (Vector3.back * distance);
        transform.position = target.position + offset;
        transform.LookAt(target);
    }
}
```

### 6.8.3 Cinematic Camera Paths

```csharp
using UnityEngine;

public class CameraPath : MonoBehaviour
{
    public Transform[] waypoints;
    public float speed = 2f;
    public bool loop = true;

    private int currentIndex = 0;
    private float t = 0f;

    void Update()
    {
        if (waypoints.Length < 2) return;

        Transform start = waypoints[currentIndex];
        Transform end = waypoints[(currentIndex + 1) % waypoints.Length];

        // Smooth interpolation
        t += Time.deltaTime * speed;
        transform.position = Vector3.Lerp(start.position, end.position, t);
        transform.rotation = Quaternion.Slerp(start.rotation, end.rotation, t);

        if (t >= 1f)
        {
            currentIndex++;
            t = 0f;

            if (currentIndex >= waypoints.Length - 1 && !loop)
            {
                enabled = false; // Stop at end
            }
            else
            {
                currentIndex %= waypoints.Length;
            }
        }
    }
}
```

### 6.9.1 ArticulationBody for Robot Joints

### 6.9.2 Collision Layers for Robots

**Setup Collision Matrix**:

```

2. Add layers:
   - Layer 8: Robot
   - Layer 9: Human
   - Layer 10: Environment
   - Layer 11: Tools

3. Edit > Project Settings > Physics
4. Layer Collision Matrix:
   - Robot ↔ Environment: ✓
```

**Assign Layers Programmatically**:

```csharp
void AssignLayers(GameObject robot)
{

    // Recursively set children
    foreach (Transform child in robot.transform)
    {
        child.gameObject.layer = LayerMask.NameToLayer("Robot");
    }
}
```

### 6.9.3 Grasping and Manipulation

**Simple Gripper Controller**:

```csharp
public class SimpleGripper : MonoBehaviour
{
    public ArticulationBody leftFinger;
    public ArticulationBody rightFinger;
    public float openAngle = 30f;
    public float closedAngle = 0f;

    private bool isOpen = true;

    public void ToggleGripper()
    {
        isOpen = !isOpen;
        SetGripperState(isOpen);
    }

    void SetGripperState(bool open)
    {
        float targetAngle = open ? openAngle : closedAngle;

        ArticulationDrive leftDrive = leftFinger.xDrive;
        leftDrive.target = targetAngle;
        leftFinger.xDrive = leftDrive;

        ArticulationDrive rightDrive = rightFinger.xDrive;
        rightDrive.target = -targetAngle; // Mirror angle
        rightFinger.xDrive = rightDrive;
    }
}
```

**Object Attachment on Grasp**:

```csharp
public class GraspDetector : MonoBehaviour
{
    private GameObject graspedObject = null;

    void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Graspable") && graspedObject == null)
        {
            graspedObject = other.gameObject;

            // Disable physics and attach to gripper
            Rigidbody rb = graspedObject.GetComponent<Rigidbody>();
            if (rb != null)
            {
                rb.isKinematic = true;
            }
            graspedObject.transform.SetParent(transform);
        }
    }

    public void ReleaseObject()
    {
        if (graspedObject != null)
        {
            graspedObject.transform.SetParent(null);

            Rigidbody rb = graspedObject.GetComponent<Rigidbody>();
            if (rb != null)
            {
                rb.isKinematic = false;
            }
            graspedObject = null;
        }
    }
}
```

### 6.10.3 Teleoperation in VR

**Map VR Controllers to Robot Arms**:

```csharp
using UnityEngine;
using UnityEngine.XR;

public class VRTeleoperation : MonoBehaviour
{
    public Transform vrLeftHand;
    public Transform vrRightHand;
    public Transform robotLeftHand;
    public Transform robotRightHand;

    public float positionScale = 1.0f; // Scale VR movements to robot
    private Vector3 leftHandInitial;
    private Vector3 rightHandInitial;

    void Start()
    {
        leftHandInitial = vrLeftHand.localPosition;
        rightHandInitial = vrRightHand.localPosition;
    }

    void Update()
    {
        // Map VR hand movements to robot hands
        Vector3 leftDelta = vrLeftHand.localPosition - leftHandInitial;
        Vector3 rightDelta = vrRightHand.localPosition - rightHandInitial;

        // Apply to robot (with scaling)
        robotLeftHand.localPosition += leftDelta * positionScale;
        robotRightHand.localPosition += rightDelta * positionScale;

        // Mirror orientations
        robotLeftHand.rotation = vrLeftHand.rotation;
        robotRightHand.rotation = vrRightHand.rotation;
    }
}
```

```csharp
// Add LOD Group to robot
```


### 6.12.2 Complete Integration Script

```csharp
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Sensor;
using RosMessageTypes.Std;

public class HumanoidVisualizer : MonoBehaviour
{
    [Header("ROS Configuration")]
    public string rosIPAddress = "127.0.0.1";
    public int rosPort = 10000;

    [Header("Robot Components")]
    public GameObject robotPrefab;
    private GameObject robotInstance;
    private ArticulationBody[] joints;

    [Header("Visualization")]
    public Material defaultMaterial;
    public Material alertMaterial;

    private ROSConnection ros;
    private bool isConnected = false;

    void Start()
    {
        // Initialize ROS connection
        ros = ROSConnection.GetOrCreateInstance();
        ros.ConnectOnStart = false;
        ros.RosIPAddress = rosIPAddress;
        ros.RosPort = rosPort;
        ros.Connect();

        // Subscribe to topics
        ros.Subscribe<JointStateMsg>("/joint_states", OnJointStateReceived);
        ros.Subscribe<StringMsg>("/robot/status", OnStatusReceived);

        // Instantiate robot
        robotInstance = Instantiate(robotPrefab, Vector3.zero, Quaternion.identity);
        joints = robotInstance.GetComponentsInChildren<ArticulationBody>();

        Debug.Log($"Initialized with {joints.Length} articulation bodies");
    }

    void OnJointStateReceived(JointStateMsg msg)
    {
        for (int i = 0; i < msg.name.Length && i < joints.Length; i++)
        {
            if (joints[i] != null)
            {
                ArticulationDrive drive = joints[i].xDrive;
                drive.target = (float)msg.position[i] * Mathf.Rad2Deg;
                joints[i].xDrive = drive;
            }
        }
    }

    void OnStatusReceived(StringMsg msg)
    {
        Debug.Log($"Robot status: {msg.data}");

        // Change robot color based on status
        if (msg.data == "alert")
        {
            SetRobotMaterial(alertMaterial);
        }
        else
        {
            SetRobotMaterial(defaultMaterial);
        }
    }

    void SetRobotMaterial(Material mat)
    {
        foreach (var renderer in robotInstance.GetComponentsInChildren<Renderer>())
        {
            renderer.material = mat;
        }
    }

    void OnDestroy()
    {
        if (ros != null)
        {
            ros.Disconnect();
        }
    }
}
```

## 6.13 Best Practices for Unity Robotics Visualization

### 1. Coordinate System Consistency

Always convert between Unity (Y-up, left-handed) and ROS (Z-up, right-handed):

```csharp
public static class CoordinateConverter
{
    // Unity to ROS
    public static Vector3 UnityToROS(Vector3 unityVec)
    {
        return new Vector3(unityVec.z, -unityVec.x, unityVec.y);
    }

    // ROS to Unity
    public static Vector3 ROSToUnity(Vector3 rosVec)
    {
        return new Vector3(-rosVec.y, rosVec.z, rosVec.x);
    }

    // Unity to ROS (Quaternion)
    public static Quaternion UnityToROS(Quaternion unityQuat)
    {
        return new Quaternion(unityQuat.z, -unityQuat.x, unityQuat.y, unityQuat.w);
    }
}
```

## 6.14 Troubleshooting Common Issues

### Issue 1: URDF Import Fails

**Symptoms**: Missing meshes, incorrect transforms

**Solutions**:
1. Check mesh file paths in URDF (use absolute or `package://`)
2. Ensure all mesh files (.dae, .stl) are in correct directories
3. Verify URDF syntax with `check_urdf` (ROS tool)
4. Use Y-up axis conversion in import settings

### Issue 2: ArticulationBody Instability

**Symptoms**: Jittering, exploding joints

**Solutions**:
```csharp
// Increase solver iterations
ArticulationBody body = GetComponent<ArticulationBody>();
body.solverIterations = 20;
body.solverVelocityIterations = 10;

// Reduce drive stiffness
ArticulationDrive drive = body.xDrive;
drive.stiffness = 1000f; // Lower value
drive.damping = 100f;
body.xDrive = drive;

// Enable continuous collision detection
body.collisionDetectionMode = CollisionDetectionMode.Continuous;
```

### Issue 3: ROS Connection Timeouts

**Symptoms**: "Connection refused" or timeout errors

**Solutions**:
1. Verify ROS-TCP-Endpoint is running:
   ```bash
   ros2 run ros_tcp_endpoint default_server_endpoint
   ```
2. Check firewall settings (open port 10000)
3. Use correct IP address:
   - Same machine: `127.0.0.1`
   - Network: `192.168.x.x` (local IP)
4. Test connection:
   ```bash
   nc -zv 127.0.0.1 10000
   ```

### Issue 4: Low FPS / Performance

**Solutions**:
1. Reduce shadow quality and distance
2. Enable occlusion culling
3. Use LOD groups
4. Lower physics update rate
5. Reduce post-processing effects
6. Profile with Unity Profiler to identify bottleneck
